Guía completa para aprender **Kotlin + Android** sin experiencia previa en desarrollo móvil,
construyendo una app real paso a paso: una Pokédex con login, listado, detalle y favoritos.

> **¿Para quién es esto?** Para alguien que nunca vio Kotlin ni desarrollo móvil.
> Saber algo de programación (por ejemplo JavaScript) ayuda, y la guía marca los
> paralelismos, pero cada concepto se explica desde cero.

## Cómo leer esta guía

- Los capítulos van **en orden**. Cada uno asume solo lo visto en los anteriores.
- Cada capítulo termina con un **checkpoint**: si no podés tildar todo, releé antes de avanzar.
- Los términos en negrita están definidos en el [Glosario](/recursos/glosario/).

## Capítulos

| # | Capítulo | Qué aprendés | Estado |
|---|----------|--------------|--------|
| 00 | [Introducción](/capitulos/00-introduccion/) | Qué vamos a construir, el mapa de tecnologías y la arquitectura a vuelo de pájaro | ✅ |
| 01 | [El entorno](/capitulos/01-entorno/) | Instalar Android Studio, crear el proyecto y entender qué generó | ✅ |
| 02 | [Kotlin esencial](/capitulos/02-kotlin-esencial/) | El lenguaje: variables, funciones, clases, null safety | ✅ |
| 03 | Primera pantalla con Compose | UI declarativa y el concepto de estado | ⏳ |
| 04 | Login (MVVM + State/Intent) | La primera funcionalidad completa con arquitectura | ⏳ |
| 05 | Navegación | NavGraph, rutas y Bottom Navigation Bar | ⏳ |
| 06 | Lista de Pokémon (Retrofit) | Consumir una API REST real: DTOs, mappers, Repository | ⏳ |
| 07 | Inyección de dependencias (Hilt) | Dejar de instanciar todo a mano | ⏳ |
| 08 | Detalle del Pokémon | Navegación con parámetros | ⏳ |
| 09 | Favoritos (Room) | Base de datos local y persistencia | ⏳ |
| 10 | Sincronización y pulido | Estado consistente entre pantallas, carga y errores | ⏳ |

Los capítulos marcados ⏳ se escriben a medida que avanzamos — esta guía se construye
junto con el proyecto, no antes.
