Guía completa para aprender **Kotlin + Android** sin experiencia previa en desarrollo móvil,
construyendo una app real paso a paso: una Pokédex con login, listado, detalle y favoritos.

> **¿Para quién es esto?** Para alguien que nunca vio Kotlin ni desarrollo móvil.
> Saber algo de programación (por ejemplo JavaScript) ayuda, y la guía marca los
> paralelismos, pero cada concepto se explica desde cero.

## Cómo leer esta guía

- Los capítulos van **en orden**. Cada uno asume solo lo visto en los anteriores.
- Cada capítulo termina con un **checkpoint**: si no podés tildar todo, releé antes de avanzar.
- Los términos en negrita están definidos en el [Glosario](/pokedex/recursos/glosario/).

## Capítulos

| # | Capítulo | Qué aprendés | Estado |
|---|----------|--------------|--------|
| 00 | [Introducción](/pokedex/capitulos/00-introduccion/) | Qué vamos a construir, el mapa de tecnologías y la arquitectura a vuelo de pájaro | ✅ |
| 01 | [El entorno](/pokedex/capitulos/01-entorno/) | Instalar Android Studio, crear el proyecto y entender qué generó | ✅ |
| 02 | [Kotlin esencial](/pokedex/capitulos/02-kotlin-esencial/) | El lenguaje: variables, funciones, clases, null safety | ✅ |
| 03 | [Primera pantalla con Compose](/pokedex/capitulos/03-primera-pantalla/) | UI declarativa: composables, previews, `Column`/`Row` y `Modifier` | ✅ |
| 04 | [Tarjetas y listas con Material](/pokedex/capitulos/04-tarjetas-material/) | `Card`, tipografía de Material 3 y `LazyColumn` | ✅ |
| 05 | [Estado y recomposición](/pokedex/capitulos/05-estado/) | `remember`, `mutableStateOf`, recomposición y state hoisting | ✅ |
| 06 | [Login: arquitectura y estado](/pokedex/capitulos/06-login-arquitectura/) | Clean Architecture, MVVM y el patrón State/Intent — más el Kotlin que necesitan: `interface`, `object` y `sealed class` | 🚧 |
| 07 | Navegación | NavGraph, rutas y Bottom Navigation Bar | ⏳ |
| 08 | Lista de Pokémon (Retrofit) | Consumir una API REST real: corrutinas, `Flow`, DTOs, mappers, Repository e imágenes | ⏳ |
| 09 | Inyección de dependencias (Hilt) | Dejar de instanciar todo a mano | ⏳ |
| 10 | Detalle del Pokémon | Navegación con parámetros | ⏳ |
| 11 | Favoritos (Room) | Base de datos local y persistencia | ⏳ |
| 12 | Sincronización y pulido | Estado consistente entre pantallas, carga y errores | ⏳ |

Los capítulos marcados ⏳ se escriben a medida que avanzamos — esta guía se construye
junto con el proyecto, no antes.
